Important limitations

This is experimental software, not financial advice or a recommendation to trade. Strategy rules and replay results do not demonstrate profitability. Use data you are licensed to use. No data provider API is connected to this public page. The local app includes a T4 simulator data client that requires authorized account access and verification; live order routing is not implemented. Live orders are disabled.

Run the actual paper replay locally

The browser preview does not run strategy logic or calculate performance. Clone the source, install the .NET 10 SDK, then point the replay runner at your own licensed CSV:

git clone https://github.com/bibek061/bot-for-trading-.git
cd bot-for-trading-
dotnet test
dotnet run --project src\AutopilotQuant.Runner -- replay "C:\path\to\your-data.csv" --report-json "C:\path\to\replay-report.json"

The paper runner processes the file locally, applies configured risk checks and simulated costs, and writes the report to your chosen local path. It does not upload bars or reports.

What the local runner does

  • Classifies regimes using the current ATR(14), EMA(20), and EMA(50) research baseline.
  • Evaluates the long-only EMA20 pullback/reclaim signal on completed bars.
  • Checks daily-loss, drawdown, connection, and open-position limits before paper entries.
  • Simulates MES/MNQ fills, configured slippage and fees, and exports run and trade results.

Replay is simplified: it does not model queue position, partial fills, market impact, all exchange fees, or outages. Test assumptions with trustworthy out-of-sample data.
