Autopilot Quant

A .NET project for exploring a guarded futures research workflow: historical bars, market-regime classification, paper signals, risk checks, and simulated MES/MNQ fills.

View the source on GitHub

Important limitations

This is experimental software, not financial advice or a recommendation to trade. Strategy rules and sample results are not evidence of profitability. The included market-data CSV is fabricated synthetic data, not historical exchange data. T4 market data and live order routing are not implemented; live orders are disabled.

Current workflow

Replay

Read OHLCV CSV bars with explicit timestamps and replay them in chronological order using the configured trading timezone.

Classify

Use an initial ATR(14), EMA(20), and EMA(50) baseline to label bars as risk-off, trend, chop, or insufficient data.

Simulate safely

Evaluate a long-only EMA20 pullback/reclaim candidate, run risk checks, and simulate fees and slippage in paper mode.

Try the synthetic example

With the .NET 10 SDK installed, clone the repository and run:

dotnet test
dotnet run --project src\AutopilotQuant.Runner -- replay data\sample_mes_5m_synthetic.csv --report-json data\sample-report.json

The output is a software smoke test only. Do not interpret it as a backtest or performance claim.

Safety and status

  • Live T4 orders are not connected or enabled.
  • Short entries remain locked by default.
  • Risk limits and regime thresholds require validation with trustworthy historical data.
  • Replay currently simulates fills; it does not model queue position, partial fills, market impact, or exchange outages.
